# 문제 가설 검증 계획

- 상태: proposed
- 최종 검토일: 2026-07-16
- 관련 작업: TASK-012

## 목적

[문제 및 근거 조사](research-basis.md)에 기록한 현장 가설을 전문가와 보호자의 실제 경험으로 검증한다. 인터뷰가 어려운 경우 대체 자료를 수집하되, 직접 확인하지 않은 가설을 검증 완료로 표시하지 않는다.

## 검증할 가설

| ID | 가설 | 확인할 근거 |
| --- | --- | --- |
| HYP-001 | 전문 인력 부족이 조기 지원을 지연시킨다. | 대기 기간, 지원을 받지 못한 사례, 담당 인원과 수용 규모 |
| HYP-002 | 아동별 분석과 교안 제작이 전문가 업무의 병목이다. | 작업 절차, 소요 시간, 반복 작업과 자동화 가능 범위 |
| HYP-003 | 비용·이동·일정 제약이 지속적인 훈련을 방해한다. | 중단 이유, 방문 빈도, 가정 훈련의 어려움 |
| HYP-004 | 보호자와 전문가가 장기 변화를 함께 판단할 기록이 부족하다. | 현재 기록 방식, 의사결정에 필요한 정보, 누락되는 정보 |

## 권장 참여자

- 난독증·문해교육 또는 읽기중재 경험이 있는 전문가 3명 이상
- 난독증 또는 읽기곤란 지원 경험이 있는 보호자 5명 이상
- 필요하면 초등 저학년 교사, 기초학력 담당자와 교육지원기관 실무자를 보조 참여자로 포함한다.

위 인원은 통계적 대표성을 확보하기 위한 표본이 아니라 반복되는 문제와 예외를 탐색하기 위한 초기 기준이다. 아동은 초기 인터뷰 대상에 포함하지 않는다.

## 인터뷰 원칙

- 최근에 실제로 겪은 사례와 행동을 먼저 질문하고 기능 아이디어나 선호는 뒤에 묻는다.
- 특정 답을 유도하거나 iRead의 기능 필요성을 전제로 질문하지 않는다.
- 아동의 이름, 학교, 연락처, 진단서와 음성 등 식별 가능한 개인정보를 수집하지 않는다.
- 인터뷰 목적, 기록 방식, 보관 기간과 철회 방법을 사전에 알린다.
- 인터뷰 결과는 의료 진단이나 개인별 치료 조언으로 사용하지 않는다.

## 전문가 질문

1. 최근 읽기곤란 아동을 처음 지원한 과정을 순서대로 설명해 달라.
2. 아동의 어려움을 파악할 때 어떤 자료와 평가 결과를 사용하는가?
3. 한 아동의 훈련 방향과 교안을 준비하는 데 어떤 작업이 필요하고 얼마나 걸리는가?
4. 반복적이거나 시간이 많이 드는 작업은 무엇인가?
5. 현재 기록만으로 아동의 변화를 판단하기 어려웠던 사례가 있는가?
6. 보호자·교사와 정보를 공유할 때 필요한 내용과 공유하기 어려운 내용은 무엇인가?
7. 소프트웨어가 보조할 수 있는 범위와 반드시 전문가가 판단해야 하는 범위는 어디까지인가?
8. 시선·음성 데이터가 유용하려면 어떤 정확도, 설명과 검토 절차가 필요한가?
9. 자동 생성된 훈련 자료를 사용한다면 어떤 검수 기준과 수정 권한이 필요한가?
10. 도입을 거부하게 만드는 가장 큰 위험이나 부담은 무엇인가?

## 보호자 질문

1. 아동의 읽기 어려움을 처음 인지한 계기와 이후 지원 과정을 설명해 달라.
2. 적절한 전문가나 프로그램을 찾는 과정에서 가장 어려웠던 점은 무엇인가?
3. 비용, 이동, 일정과 대기 기간 중 실제 이용에 가장 큰 영향을 준 것은 무엇인가?
4. 가정에서 훈련을 지속하기 어려웠던 상황과 이유는 무엇인가?
5. 아동의 변화를 확인할 때 현재 어떤 정보에 의존하는가?
6. 전문가나 교사에게 어떤 정보를 받고 싶었으며 실제로 부족했던 것은 무엇인가?
7. 시선·음성 데이터를 수집한다면 허용하기 어려운 항목이나 조건은 무엇인가?
8. 시스템 결과와 전문가 의견이 다를 때 어떤 설명과 절차가 필요한가?
9. 아동이 훈련을 거부하거나 힘들어할 때 현재 어떻게 대응하는가?
10. 서비스 사용을 중단하게 만들 수 있는 가장 큰 우려는 무엇인가?

## 인터뷰가 어려울 때의 대체 검증

| 우선순위 | 방법 | 확보할 수 있는 근거 | 한계 |
| --- | --- | --- | --- |
| 1 | 전문가 1명 이상의 문서 검토 | 현장 절차와 책임 경계의 오류 확인 | 보호자 경험을 확인할 수 없음 |
| 2 | 익명 온라인 설문 | 문제 빈도와 우선순위의 방향성 | 맥락과 원인을 깊게 확인하기 어려움 |
| 3 | 교사·교육지원기관 실무자 인터뷰 | 학교 지원 절차와 자원 병목 | 가정과 치료실 경험을 대체하지 못함 |
| 4 | 공공 보고서·학술 연구 검토 | 유병률, 지원 체계와 중재 근거 | iRead가 해결할 현장 업무 문제를 직접 검증하지 못함 |
| 5 | 팀 내부 가설 점검 | 빠른 MVP 논의 | 사용자 근거가 아니므로 검증으로 간주할 수 없음 |

인터뷰 없이 TASK-003을 진행하면 HYP-001부터 HYP-004를 `[ASSUMPTION]`으로 유지하고, MVP 결과를 사용자 문제 검증이 아닌 기술·사용성 탐색으로 제한한다.

## 기록 양식

| 항목 | 기록 내용 |
| --- | --- |
| 참여자 유형 | 전문가 / 보호자 / 교사 / 지원기관 |
| 관련 경험 | 역할과 경험 기간을 식별 불가능한 범위에서 기록 |
| 관찰된 사실 | 참여자가 실제로 수행하거나 경험한 내용 |
| 해석 | 팀의 해석이며 사실과 분리해서 기록 |
| 관련 가설 | HYP-001 ~ HYP-004 |
| 반대 사례 | 가설과 맞지 않는 경험 |
| 후속 확인 | 추가 질문이나 필요한 자료 |

## 완료 조건

- 질문지와 기록 양식이 준비되어 있다.
- 참여자의 동의와 개인정보 비수집 원칙이 정해져 있다.
- 각 가설에 대해 `supported`, `partially-supported`, `not-supported`, `unverified` 중 하나를 근거와 함께 기록한다.
- 전문가와 보호자 양쪽의 직접 근거가 없으면 TASK-012를 완료 처리하지 않고 한계를 기록한다.
