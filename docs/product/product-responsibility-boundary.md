# 제품 용어 및 책임 경계

- 상태: proposed
- 최종 검토일: 2026-07-16
- 관련 작업: TASK-013

## 결론

제품의 최종 분류와 규제 검토가 끝나기 전까지 iRead는 `교육용 읽기 훈련 및 학습 지원 시스템`을 임시 운영 경계로 사용한다. 시스템은 훈련 과정에서 관찰한 수행을 정리하고 전문가와 보호자의 판단을 보조할 수 있지만, 난독증을 진단하거나 치료를 처방하고 임상적 효과를 보장하지 않는다.

이 경계는 최종 제품 범위를 확정한 결정이 아니다. 내부 기능 회의에서 진단·치료 목적을 포함하기로 하면 디지털의료제품 해당 여부, 허가·임상 근거와 책임 체계를 별도로 검토해야 한다.

## 용어 사용 기준

| 용어 | iRead 문서와 화면에서의 기준 | 현재 사용 |
| --- | --- | --- |
| 진단 | 질환이나 장애 여부를 전문적 기준에 따라 판단하는 행위 또는 결과 | 사용하지 않음 |
| 선별 | 추가 평가가 필요한 위험 신호를 찾는 과정. 진단과 구분하고 한계와 후속 절차를 함께 안내 | `읽기곤란 위험 신호 확인`으로 제한 |
| 평가 | 의료적 판단으로 오해될 수 있으므로 대상과 기준을 구체적으로 표현 | `훈련 수행 분석`, `읽기 활동 결과` 사용 |
| 학습 프로파일 | 훈련 중 관찰된 수행, 어려움과 변화 기록 | 사용 가능, 의료 진단이 아님을 명시 |
| 훈련 | 읽기·음운 관련 능력 향상을 돕는 교육 활동 | 현재 제품 목적에 사용 가능 |
| 치료 | 질환이나 장애의 개선을 목적으로 하는 임상적 개입 | 규제·전문가 검토 전 사용하지 않음 |
| 효과 | 검증된 측정과 비교 근거가 있을 때만 제한적으로 표현 | `개선 보장`, `치료 효과` 표현 금지 |

`정밀 진단`, `AI 진단`, `난독증 확률`, `치료 처방`, `완치`처럼 의료적 판단이나 효능을 암시하는 표현은 현재 범위에서 사용하지 않는다.

## 시스템이 제공할 수 있는 범위

- 합의된 읽기 훈련 활동 제공
- 정답률, 반응 시간과 훈련 참여 이력 기록
- 별도 동의를 받은 경우에 한해 합의된 시선·음성 지표 처리
- 관찰된 어려움과 변화의 설명 가능한 요약
- 보호자와 전문가가 검토할 수 있는 훈련 자료 후보 제시
- 위험 신호가 있을 때 전문가 평가를 권고하는 안내

## 시스템이 단독으로 수행하지 않는 범위

- 난독증 또는 특정학습장애 확정
- 의료적 중증도나 치료 필요성 판정
- 전문가 검토 없는 훈련 교안 확정과 치료 방향 변경
- 시스템 결과만을 근거로 한 학교·치료·복지 의사결정
- 검증되지 않은 지표를 이용한 아동 간 서열화
- 동의 목적을 벗어난 모델 학습, 광고와 제3자 제공

## 역할별 책임

| 역할 | 책임 |
| --- | --- |
| iRead 시스템 | 데이터의 출처와 분석 한계를 설명하고 결과를 수정·검토할 수 있게 제공한다. 오류나 불확실성을 숨기지 않는다. |
| 보호자 | 아동이 이해할 수 있도록 참여를 설명하고 동의·철회와 전문가 상담 여부를 결정한다. 시스템 결과를 진단으로 해석하지 않는다. |
| 전문가·교육자 | 자신의 자격과 전문 기준에 따라 결과를 독립적으로 검토하고 최종 지원 방향을 판단한다. |
| 운영 팀 | 허용된 표현, 접근 권한, 보관·삭제, 안전성 검토와 사고 대응 절차를 유지한다. |

## 아동 데이터 처리 기준

- 만 14세 미만 아동의 개인정보 처리에 동의가 필요하면 법정대리인의 동의를 받고 실제 동의 여부를 확인한다.
- 아동에게는 수집 목적, 항목, 이용 방식과 철회 방법을 이해하기 쉬운 표현으로 알린다.
- 건강 또는 장애 관련 정보는 민감정보에 해당할 수 있으므로 일반 개인정보와 구분해 처리 근거와 별도 동의 필요성을 검토한다.
- 시선·음성 원본과 파생 지표는 수집 목적, 식별 가능성과 건강 상태 추론 여부에 따라 개인정보·민감정보 해당 가능성을 검토한다.
- 원본 데이터가 없어도 목적을 달성할 수 있으면 원본을 저장하지 않는다.
- 연구·분석 목적의 음성 원본과 보고서를 장기 보관할 때는 수집 항목, 목적, 보관 기간, 접근 주체, 철회와 삭제 방법을 명시한 별도 동의를 받는다.
- 동의 철회 또는 명시한 보관 기간 종료 시 원본과 연결 가능한 파생 데이터를 삭제한다.
- 음성 파일 경로를 외부에 직접 공개하지 않고 인증된 Backend를 통해서만 접근한다.
- 외부 AI 모델이나 분석 서비스에 전송하기 전 처리 위치, 국외 이전, 재학습 여부와 삭제 보장을 확인한다.

## 진단·치료 범위로 확장하기 위한 조건

다음 조건을 모두 검토하기 전에는 진단·치료 목적을 제품 범위로 확정하지 않는다.

1. 식품의약품안전처 또는 관련 전문가를 통한 제품 분류 검토
2. 대상 연령·언어·환경에 적합한 임상적 성능과 안전성 근거
3. 결과를 검토하고 책임질 전문가의 자격과 역할
4. 오탐·미탐, 부적절한 훈련과 아동의 심리적 피해 대응 절차
5. 법정대리인 동의, 아동 설명, 민감정보와 국외 이전 기준
6. 결과 정정, 이의 제기, 사용 중단과 데이터 삭제 절차
7. 홍보 문구와 사용자 안내에 대한 법률·규제 검토
