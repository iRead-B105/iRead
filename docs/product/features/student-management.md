# 기능 명세: 학습자 관리와 교수 메모

- 상태: accepted
- 관련 기능: `MH-SAVE-01`~`MH-SAVE-07`

## 기대 결과

교수자는 학습자 정보와 학습 지도용 단일 메모를 수정할 수 있다.

## 수용 기준

- 교수 메모는 `students.teacher_memo`에 저장한다.
- 별도 학습 메모 목록과 수정 이력은 생성하지 않는다.
- 학습 이벤트 내용은 현재 교수 메모 입력값에 추가한 뒤 하나의 메모로 저장한다.
- 별도 학습 이벤트 확인 완료 상태는 저장하지 않는다.
- 인증 주체와 학습자 소유 관계는 access token으로 검증한다.

## 제외 범위

- 아동 응원과 메시지 전달
- 응원 전달 시점과 전달 이력
- 메모별 공개 범위와 확인 완료 상태
