# 기능 명세: 이야기 책장 관리

- 상태: accepted
- 관련 기능: `ST-LIB-01`~`ST-LIB-12`, `ST-DTL-04`, `ST-READ-02`

## 기대 결과

아동은 진행 중인 이야기와 다 읽은 이야기를 별도 탭에서 구분해 보고, 진행 중인 이야기만 제목과 진행률을 확인한 뒤 책장에서 삭제할 수 있다. 여러 종류와 같은 종류의 이야기를 동시에 진행할 수 있지만 진행 중인 이야기는 아동별 최대 15권까지 보관한다.

## 수용 기준

- 읽던 책 화면은 `읽는 중`과 `다 읽은 책` 탭을 제공하며 기본 탭은 `읽는 중`이다.
- `읽는 중` 탭에는 `IN_PROGRESS`, `다 읽은 책` 탭에는 `COMPLETED` 이야기만 표시한다.
- `DELETED` 이야기는 아동 책장과 교사 이야기 조회에서 제외한다.
- 아동별 `IN_PROGRESS` 이야기는 최대 15권이며 `COMPLETED`와 `DELETED`는 한도에 포함하지 않는다.
- 같은 이야기 템플릿으로 여러 `IN_PROGRESS` 세션을 동시에 만들 수 있다.
- 15권에 도달한 새 이야기 시작 요청은 `409 Conflict`로 거부하고 기존 이야기를 자동 삭제하지 않는다.
- 아동은 `IN_PROGRESS` 이야기만 삭제할 수 있고 `COMPLETED` 이야기 삭제 요청은 `409 Conflict`로 거부한다.
- 삭제 전 확인 팝업에 이야기 제목과 현재 진행률을 표시한다.
- 삭제를 확정하면 이야기 상태를 `DELETED`로 변경하고 성공 응답 직후 현재 책장에서 제거한다.
- 삭제는 이야기 세션에만 적용하며 `story_templates`와 템플릿 표지는 변경하거나 삭제하지 않는다.
- 삭제 후 같은 템플릿으로 새 이야기 세션을 처음부터 시작할 수 있다.
- 카드 목록은 그림자와 호버 상태가 목록 컨테이너 경계에서 잘리지 않아야 한다.
- 아동 선택 로그인 성공 시 해당 아동의 책장 조회를 시작하고 결과를 아동 식별자별 메모리 캐시에 보관한다.
- 이야기 나라 재진입은 준비된 책장 캐시를 첫 렌더부터 사용하며 동일 아동의 진행 중 요청을 중복 호출하지 않는다.
- 책장 캐시가 아직 준비되지 않은 경우 실제 데이터와 혼동되는 임시 이어읽기 콘텐츠를 표시하지 않고 로딩 상태를 표시한다.
- 새 이야기 시작 시 책장 캐시를 무효화하고, 이야기 삭제 성공 시 캐시에서도 해당 세션을 즉시 제거한다.
- 이야기 읽기 진행률이 바뀌면 기존 캐시를 오래된 상태로 표시하고, 책장 재진입 시 캐시를 즉시 표시한 뒤 최신 데이터로 갱신한다.
- 아동 선택 직후 각 기존 이야기의 진입 장면 이미지를 브라우저에 미리 로딩한다.
- 독서 화면은 실제 진입 장면 이미지가 준비되기 전에 정적 이야기 이미지를 노출하지 않는다.
- 신규 이야기 본문은 구성된 실제 AI 공급자로 생성하고 생성 로그에 공급자와 모델을 남긴다.
- 생성된 모든 페이지가 분량·대화문·읽기 난이도 품질 계약을 통과해야 저장한다.
- 품질 계약 실패 시 최대 2회 다시 생성하고 계속 실패하면 `502 Bad Gateway`로 응답하며 생성 중인 이야기 세션과 장면은 저장하지 않는다.
- 생성된 장면 이미지는 아동·이야기 소유권을 확인하는 인증 API로 조회하고 클라이언트는 인증 응답을 Blob URL로 표시한다.
- 이야기 텍스트와 이미지는 `STORY_TEXT_PROVIDER`/`STORY_TEXT_MODEL`, `STORY_IMAGE_PROVIDER`/`STORY_IMAGE_MODEL`로 독립 선택하고 AI 서비스 재시작 후 적용한다.
- 신규 이야기 장면과 캐릭터 이미지는 서버의 허용 목록으로 찾은 원본 책 표지를 참조 이미지로 첨부한다.
- 글 보기 모드는 넓은 단색 본문 패널, 어두운 단색 글자, 여유 있는 자간·줄간격과 그림 감광을 적용하며 글자 그림자를 사용하지 않는다.
- 그림 보기 모드는 생성 장면을 우선 노출하고 본문은 이미지 하단의 작은 고대비 패널에 표시한다.
- 교사 이야기 이력은 생성 장면을 배경으로 사용하고 로드 실패 시 플레이스홀더를 표시하며, 본문 단어에 시선 체류 강도를 표시한다.

## API와 데이터

- `GET /api/app/story/{studentId}`: 로그인 직후 사전 조회해 캐시할 `DELETED` 제외 이야기와 템플릿, 상태별 `entryImageUrl` 조회
- `POST /api/app/story/{studentId}/{storyTemplateId}/sessions`: 진행 중 15권 제한을 확인한 뒤 새 세션 생성
- `DELETE /api/app/story/{studentId}/sessions/{storyId}`: 소유한 진행 중 이야기 소프트 삭제
- `GET /api/app/story/{studentId}/{storyId}/images/{fileName}`: 소유한 이야기의 생성 이미지 바이너리 조회
- `stories.status`: `IN_PROGRESS`, `COMPLETED`, `DELETED`
