# 용어집

- 상태: draft
- 최종 검토일: 2026-07-16

제품과 팀에서 같은 의미로 사용해야 하는 용어를 기록한다.

| 용어 | 정의 | 상태 |
| --- | --- | --- |
| iRead | 이 프로젝트의 확정된 서비스명 | accepted |
| 난독증 | 단어 읽기의 정확성·유창성, 해독 또는 철자에 지속적인 어려움이 나타나는 특정학습장애를 설명할 때 사용하는 용어 | accepted |
| 읽기곤란 위험 아동 | 읽기 발달에 어려움이 관찰되어 추가 평가나 지원이 필요할 수 있으나 난독증 진단 여부를 전제하지 않는 아동 | accepted |
| 진단 | 질환이나 장애 여부를 전문적 기준에 따라 판단하는 행위 또는 결과. 현재 iRead가 제공하는 범위가 아님 | proposed |
| 선별 | 추가 평가가 필요한 위험 신호를 찾는 과정. 진단을 의미하지 않음 | proposed |
| 훈련 | 읽기·음운 관련 능력 향상을 돕는 교육 활동 | accepted |
| 치료 | 질환이나 장애의 개선을 목적으로 하는 임상적 개입. 규제·전문가 검토 전에는 iRead의 효능으로 표현하지 않음 | proposed |
| 학습자 | iRead의 읽기 훈련에 참여하는 초등 저학년 아동 | accepted |
| 보호자 | 학습자의 훈련 참여와 개인정보 처리에 관여하는 부모 또는 법정대리인 | accepted |
| 전문가 | 난독증·문해교육, 언어치료 또는 관련 교육 지원을 담당하는 사람. 제품에서 허용할 역할과 자격 기준은 미정 | draft |
| 학습 프로파일 | 읽기 훈련 과정에서 관찰된 수행과 어려움의 특성을 정리한 기록. 의료 진단을 의미하지 않음 | proposed |
| 훈련 교안 | 학습자의 읽기 훈련 목표, 자극과 활동 순서를 구성한 자료 | proposed |
| 멀티모달 데이터 | 시선, 음성처럼 서로 다른 입력 방식에서 수집되는 데이터. 실제 수집 항목과 목적은 미정 | draft |
| 오케스트레이션 저장소 | 서비스 구현이 아니라 공통 기획, 계약, 의사결정과 통합 구성을 관리하는 저장소 | accepted |
| Backend | Spring Boot 기반의 도메인/API 서비스 저장소. 구체적 책임은 미정 | draft |
| Frontend | Vue 기반의 사용자 인터페이스 저장소. 대상 사용자와 화면 범위는 미정 | draft |
| AI server | FastAPI 기반의 AI 관련 기능 제공 저장소. 모델과 책임은 미정 | draft |
| Redis | 캐시·세션·메시징 후보 인프라. 실제 역할은 미정 | draft |

## 추가 규칙

- 동의어는 대표 용어로 연결한다.
- 기술 구현이 아니라 비즈니스 의미를 우선 설명한다.
- 의미가 바뀌면 영향을 받는 요구사항 식별자를 함께 기록한다.
