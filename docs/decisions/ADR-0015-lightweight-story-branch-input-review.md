# ADR-0015: 경량 LLM으로 이야기 음성 분기 입력 검토

- 상태: accepted
- 결정일: 2026-08-04

## 배경

이야기 자유 음성 분기는 STT 신뢰도와 짧은 문자열 검증만 거친 뒤 아동 확인을 받아 이야기 생성에 전달했다. 이 방식은 현재 분기와 무관하거나 아동에게 부적절한 입력을 생성 모델에 전달할 수 있고, 최종 JSON API에 임의의 `branchIntent`를 보내 검토 단계를 우회할 수 있다.

난독증 아동의 표현과 발화 특성을 보존해야 하므로 LLM이 STT 문장을 자동 교정하거나 의도를 새로 작성해서는 안 된다. 동시에 검토 지연이 이야기 흐름을 방해하지 않도록 입력과 출력을 최소화해야 한다.

## 결정

- Backend는 STT 직후 AI server의 경량 분기 입력 검토 API를 호출한다.
- 검토 입력은 현재 분기 질문, 버튼 선택지 3개와 STT 원문으로 제한하고 학생 식별자·음성·전체 이야기 기록은 모델에 전달하지 않는다.
- 검토 결과는 `ALLOW`, `CONFIRM`, `RETRY`, `BLOCK`과 제한된 사유 코드만 반환하며 교정문과 자유 형식 설명을 금지한다.
- 안전성 판정을 관련성보다 먼저 적용하고 명시된 고위험 범주만 `BLOCK`한다.
- `ALLOW`와 `CONFIRM` 원문은 아동 확인 후 사용하고 `RETRY`와 `BLOCK`은 이야기 생성과 최종 선택 저장에서 제외한다.
- Backend는 검토 원문·이야기·분기 대사에 결합된 단기 서명 토큰을 발급하고 최종 자유 음성 제출에서 검증한다.
- 최종 분기 API의 직접 음성 multipart 제출은 제거하고 버튼 번호 또는 검토 토큰이 결합된 확인 원문만 받는다.
- 검토 서비스 오류와 제한 시간 초과는 허용으로 간주하지 않고 재녹음 또는 기존 버튼 선택지로 복구한다.
- 차단 원문과 요청 본문은 로그 또는 별도 데이터로 저장하지 않는다.
- 교사·보호자 자동 알림과 외부 신고는 이번 결정에 포함하지 않는다.

## 영향

- App–Backend 및 Backend–AI 계약과 세 서비스 구현을 함께 변경한다.
- 기존 최종 분기 multipart 호출자는 먼저 STT 검토 API를 호출하고 검토 토큰으로 JSON 제출하도록 전환해야 한다.
- 버튼 선택은 검토 토큰 없이 기존처럼 제출할 수 있다.
- 검토 모델과 정책 버전은 생성 모델과 독립적으로 교체할 수 있다.

## 롤백

검토 모델 장애 시 App은 저장된 버튼 선택지 3개를 계속 사용할 수 있다. 검토 기능 자체를 비활성화하더라도 자유 음성 입력을 무검토로 허용하지 않고 버튼 선택만 유지한다.
