# ADR-0016: 이야기 텍스트와 이미지 공급자를 독립적으로 라우팅

- 상태: accepted
- 결정일: 2026-08-04

## 배경

이야기 텍스트는 GMS와 OpenAI 호환 경로를 선택할 수 있지만 모델 설정이 공용 이름에 묶여 있고, 이미지는 GMS 경유 Gemini만 지원한다. 공급자 장애·비용·품질에 따라 텍스트와 이미지를 서로 다른 공급자와 모델로 운영할 수 있어야 한다.

## 결정

- 이야기 텍스트와 이미지에 독립적인 `provider`와 `model` 환경변수를 둔다.
- 지원 공급자는 `gms`, `gemini`, `openai`이며 로컬 자동 검증에는 `mock` 또는 `disabled`를 유지한다.
- 공급자 전환은 AI 서비스 환경변수 변경 후 재시작으로 적용한다. 실행 중 전환 API와 아동·교사 클라이언트의 모델 선택 기능은 제공하지 않는다.
- API 키는 AI server 환경에서만 읽고 로그, Backend 응답과 Frontend 번들에 포함하지 않는다.
- 텍스트 생성은 동일한 구조화 출력 계약을 공급자 adapter가 만족하게 하고, 기존 품질 재생성·최종 차단 정책은 공급자와 무관하게 적용한다.
- 이미지 생성은 공통 `StoryImageGenerator` port를 사용하고 장면·캐릭터마다 원본 이야기 표지를 참조 이미지로 전달한다.
- 표지는 Frontend가 업로드하지 않는다. 오케스트레이션 실행 환경이 승인된 표지 디렉터리를 AI server에 읽기 전용으로 제공하고 템플릿 ID를 허용 목록의 파일명으로 해석한다.
- 공급자와 모델은 생성 메타데이터와 안전한 구조화 로그에 기록한다.

## 영향

### 긍정적 영향

- 텍스트와 이미지 품질·비용·장애를 독립적으로 조정할 수 있다.
- 아동 클라이언트가 API 키나 임의 참조 이미지를 전달하지 않는다.
- 기존 이야기 저장 계약과 생성 이미지 인증 조회 경로를 유지한다.

### 부정적 영향과 트레이드오프

- 공급자별 구조화 출력과 이미지 편집 API 차이를 adapter 테스트로 계속 관리해야 한다.
- 표지 디렉터리를 제공하지 않는 배포에서는 참조 없이 생성하지 않고 설정 오류로 확인해야 한다.
- 공급자 변경에는 AI 서비스 재시작이 필요하다.

## 검증 및 재검토 조건

- 각 공급자 adapter의 요청 형식·오류 매핑·이미지 디코딩 테스트를 유지한다.
- 런타임 무중단 전환이 필요해지거나 공급자별 사용자 동의·데이터 국외 이전 정책이 달라지면 이 결정을 재검토한다.
