# ADR-0014: 이메일 일회용 링크로 교수자 비밀번호 재설정

- 상태: accepted
- 결정일: 2026-07-28
- 결정자: 사용자
- 대체 대상: 고정 데모 인증 코드 기반 비밀번호 재설정

## 배경

`teachers.email`은 유일한 교수자 로그인 식별자다. 기존 비밀번호 재설정 계약과 구현은 별도 로그인 아이디와 고정 데모 인증 코드를 전제로 하지만 인증 코드를 안전하게 발급·전달하는 경로가 없다. 공개된 데모에서 공통 고정 코드를 사용하면 다른 교수자 계정의 비밀번호를 변경할 수 있다.

데모에서도 실제 재설정 흐름을 검증하되 운영 메일 인프라를 필수로 만들지 않는 방법이 필요하다.

## 결정 기준

- 계정 존재 여부를 외부에 노출하지 않는다.
- 재설정 자격 증명은 짧게 유지하고 한 번만 사용할 수 있어야 한다.
- 토큰 원문을 데이터베이스와 로그에 남기지 않는다.
- 로컬 데모와 외부 배포 데모가 같은 애플리케이션 흐름을 사용한다.
- 실제 운영 전환 시 메일 발송 구현만 교체할 수 있어야 한다.

## 검토한 대안

1. 모든 계정이 공유하는 고정 데모 인증 코드를 사용한다.
2. 서명된 무상태 토큰만 사용하고 서버에는 상태를 저장하지 않는다.
3. 데이터베이스에 토큰 해시와 사용 상태를 저장하고 이메일 일회용 링크를 발송한다.

## 결정

- 사용자가 가입 이메일을 입력하면 계정 존재 여부와 관계없이 동일한 요청 접수 응답을 반환한다.
- 서버는 암호학적으로 안전한 임의 토큰을 생성하고 원문은 이메일 링크에만 포함한다.
- 데이터베이스에는 토큰의 SHA-256 해시, 교수자, 만료 시각, 사용 시각과 생성 시각을 저장한다.
- 토큰은 발급 후 10분 동안 유효하며 한 번만 사용할 수 있다.
- 같은 교수자가 새 링크를 요청하면 기존 미사용 토큰을 무효화한다.
- 비밀번호 변경과 토큰 사용 처리는 하나의 트랜잭션에서 수행한다.
- 비밀번호 변경이 완료되면 해당 교수자의 기존 refresh session을 모두 폐기한다.
- 요청과 확인 API에 계정·IP 기준 요청 제한을 적용한다.
- 로컬 데모는 Mailpit SMTP와 웹 메일함을 사용한다.
- 외부 배포 데모는 환경변수로 지정한 SMTP 서버를 사용한다.
- 토큰, 비밀번호와 요청 본문은 로그에 기록하지 않는다.

## 영향

### 긍정적 영향

- 고정 인증 코드 없이 실제 이메일 기반 재설정 흐름을 시연할 수 있다.
- 토큰의 만료, 일회성 사용과 즉시 무효화를 서버에서 보장할 수 있다.
- 로컬과 배포 환경이 같은 메일 발송 인터페이스를 사용할 수 있다.

### 부정적 영향과 트레이드오프

- `password_reset_tokens` 테이블과 만료 데이터 정리 정책이 필요하다.
- 로컬 데모 실행 구성에 Mailpit이 추가된다.
- 외부 배포 데모에서는 SMTP 자격 증명과 발신 도메인을 별도로 관리해야 한다.

## 검증 및 재검토 조건

- 존재하는 이메일과 존재하지 않는 이메일 요청이 같은 상태와 본문을 반환하는지 검증한다.
- 토큰 원문이 DB와 애플리케이션 로그에 남지 않는지 검증한다.
- 만료·재사용·재발급으로 무효화된 토큰을 거부하는지 검증한다.
- 성공 시 기존 refresh session이 모두 폐기되는지 검증한다.
- Mailpit과 환경별 SMTP 서버에서 같은 링크 형식으로 메일이 발송되는지 검증한다.
- 실제 사용자에게 공개하기 전 발신 도메인, 요청 제한 수치, 메일 전달 실패 처리와 운영 모니터링 정책을 재검토한다.
