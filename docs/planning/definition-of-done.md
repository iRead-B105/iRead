# 완료 기준

작업 완료를 선언하기 전에 관련 항목을 확인한다.

- [ ] 요청과 수용 기준을 충족한다.
- [ ] 기준 문서와 파생 문서가 일치한다.
- [ ] 새 용어, 요구사항 ID와 결정이 인덱스에 반영되었다.
- [ ] 중요한 트레이드오프가 ADR에 기록되었다.
- [ ] 보안, 개인정보와 실패 경로가 검토되었다.
- [ ] 사용자가 명시적으로 요청한 테스트·빌드·린트·정적 분석이 성공했다. 요청하지 않은 경우 미실행으로 기록했다.
- [ ] 하네스·문서 변경은 `harness-validation`이 성공했다.
- [ ] 개념 문서의 OKF frontmatter와 관련 인덱스·로그가 최신이다.
- [ ] 실행 계획과 백로그 상태가 최신이다.
- [ ] 남은 `[TBD]`, `[ASSUMPTION]`, `[BLOCKED]`가 보고되었다.
- [ ] 변경 내용, 실행한 검증 증거와 실행하지 않은 검증을 사용자가 확인할 수 있다.
