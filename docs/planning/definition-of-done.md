# 완료 기준

작업에 해당하는 항목만 확인한다.

- [ ] 요청한 결과와 수용 기준을 충족한다.
- [ ] 실제 영향을 받은 기준 원본과 파생 산출물이 일치한다.
- [ ] 변경 위험에 필요한 테스트와 검증이 성공했다.
- [ ] 구현과 필수 검증 완료 전에는 백로그·계획을 `done` 또는 `completed`로 표시하지 않았다.
- [ ] 남은 중요한 위험, 차단 사항과 필수 검증의 미실행 사유를 보고했다.

문서 추가·삭제·이름 변경이 없으면 인덱스 갱신은 필요하지 않다. 일반 문서 변경을 `docs/log.md`에 반복 기록하지 않는다.
