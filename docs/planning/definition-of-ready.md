# Definition of Ready

작업을 구현 단계로 옮기기 전에 모두 충족해야 한다.

- [ ] 목표 사용자와 해결할 문제가 명시되어 있다.
- [ ] 범위와 비범위가 구분되어 있다.
- [ ] 요구사항 ID와 관찰 가능한 수용 기준이 있다.
- [ ] 서비스/문서 소유자가 정해져 있다.
- [ ] 데이터, 보안, 실패 및 경계 조건이 확인되었다.
- [ ] 외부 의존성과 선행 결정이 해결되었다.
- [ ] 검증 방법이 정의되어 있다.
- [ ] 남은 모호성이 없거나 사용자가 명시적으로 승인한 가정으로 기록되어 있다.

충족되지 않은 항목이 작업 결과를 바꿀 수 있으면 AI 에이전트는 진행 전에 질문한다.
