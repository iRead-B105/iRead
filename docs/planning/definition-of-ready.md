# 시작 준비 기준

작업에 해당하는 항목만 확인한다.

- [ ] 목표와 관찰 가능한 완료 조건이 있다.
- [ ] 포함 범위와 제외 범위를 구분할 수 있다.
- [ ] 결과를 바꾸는 미결 결정이나 외부 차단이 해소되었거나 명시되어 있다.
- [ ] 변경 위험에 맞는 검증 방법이 있다.
- [ ] 데이터·보안·호환성 영향이 있는 작업은 해당 제약을 확인했다.

읽기 전용 탐색으로 해결할 수 있는 정보는 먼저 확인한다. 여러 타당한 선택이 남고 결과가 달라질 때만 사용자에게 질문한다.
