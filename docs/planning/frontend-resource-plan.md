- 대상: `services/frontend-app`

## 1. 현재 기준선

2026-07-30 작업트리 기준이다.

| 항목 | 값 |
| --- | ---: |
| 앱 에셋 | 146개 |
| 전체 용량 | 약 57.09 MiB |
| PNG | 123개 |
| SVG | 19개 |
| WebP·AVIF | 0개 |
| 1 MiB 이상 파일 | 20개 |
| inline SVG가 남은 Vue 파일 | 2개(기능 그래픽) |
| `!important` | 87개 |

큰 파일과 직접 색상값이 많다는 사실만으로 디자인이 잘못된 것은 아니다. 이 계획에서는 화면에서 자주 보이는 리소스, 공통 역할이 중복된 리소스, 생성형 오류 가능성이 높은 리소스와 초기 로딩에 연결된 파일을 먼저 처리한다.

## 2. 리소스 분류 상태

모든 리소스는 다음 중 하나로 분류한다.

| 상태 | 의미 |
| --- | --- |
| 유지 | 화풍·형태가 기준에 맞아 최적화만 수행 |
| 색 변경 | 형태는 유지하고 승인 팔레트로 실제 variant 생성 |
| 다듬기 | 알파, 여백, 외곽선, 비율이나 작은 생성 오류 수정 |
| 다시 만들기 | 화풍·형태·교육적 정확성이 기준과 달라 신규 제작 |
| 미사용 | 앱에서 제거하고 필요하면 원본 보관소로 이동 |
| 신규 필요 | 현재 구현에 정식 리소스가 없는 상태 |

사용자가 우선순위를 적을 수 있도록 아래 표의 `사용자 우선순위`를 비워 둔다.

## 5. Vue 전수 감사 결과

### 즉시 교체 대상

- `SoundButton.vue`의 inline SVG: 독립 듣기 상태 리소스로 교체
- 선택 카드의 런타임 CSS 필터: 실제 색상별 파일로 교체
- 첫소리 제목의 `✦` pseudo-element: 제거 후 정식 장식 대기
- `★`, `●`, `→`, `✓`, `⠿` 문자 아이콘: 공통 리소스 제작 후 교체
- 모달·헤더·훈련 화면의 inline SVG 아이콘: 공통 아이콘 폴더로 이동

### 공통 스타일 정리 대상

- 활동별 직접 HEX 색상: 공통 의미 토큰으로 이동
- 활동별 카드 크기·그림자 재정의: 공통 선택 카드 variant로 이동
- 공통 스타일을 이기기 위한 `!important`: 영향 화면 확인 후 제거
- 상세 화면의 긴 존댓말 문구: 짧은 친근한 반말로 정리
- 실제 문제보다 먼저 보이는 장식: 화면 가장자리로 이동 또는 제거

## 7. 완료 조건

- 화면에 CSS 도형과 유니코드 문자로 만든 의미 아이콘이 남지 않는다. inline SVG는 좌표가 실시간으로 바뀌는 기능 그래픽만 허용한다.
- 같은 행동은 같은 아이콘과 공통 컴포넌트를 사용한다.
- 글자·낱말·문장 카드가 정해진 비율과 세 색상 순서를 사용한다.
- 이야기 친구 4슬롯이 새로고침과 계정 전환 후에도 학생별로 유지된다.
- 5문제 중 한 번도 틀리지 않은 경우에만 올정답 완료 화면이 나타난다.
- 리소스 목록의 모든 파일이 `유지/색 변경/다듬기/다시 만들기/미사용/신규 필요` 중 하나로 분류된다.
- 필수 리소스가 없는 화면은 완료로 표시하지 않는다.
- 관련 테스트, production build와 문서 검증이 성공한다.
