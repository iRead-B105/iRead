# TASK-SYNC-001: 교수자 Web–아동 App 실시간 데이터 연동

- 상태: in-progress
- 우선순위: P0
- 관련 계획: [교수자 Web–아동 App 실시간 데이터 연동](../../plans/2026-07-31-teacher-learner-data-linkage.md)

## 목표

교수자와 아동이 같은 Backend·MySQL 데이터를 사용하고, 양쪽 앱이 온라인인 상태에서 저장 완료 후 3초 이내 상대 앱의 관련 화면을 별도 사용자 알림 없이 자동 갱신한다.

## 범위와 제약

- 포함 범위: 학생 프로필, 교육과정·훈련 편집, 훈련·검사·이야기·시선 결과, 인증된 SSE 변경 이벤트, 캐시 무효화, 데모 E2E
- 제외 범위: 교수자와 아동 앱의 직접 통신, 작성 중 입력값 공동 편집, 보고서 스냅샷 자동 재작성, 다중 Backend 이벤트 브로커
- 교수자 편집은 `NOT_READY`·`NOT_STARTED` 훈련에만 허용하고 `IN_PROGRESS`·`COMPLETED`는 기존 정책대로 거부한다.
- 보고서는 완료 데이터 기반 생성 시점 스냅샷으로 유지한다. 교수자 메모와 명시적 시선 추이 갱신만 기존 변경 동작을 유지한다.
