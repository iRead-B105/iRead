# Roadmap

- Status: proposed
- Last reviewed: 2026-07-15

날짜를 임의로 약속하지 않고 검증 가능한 단계로 관리한다.

## Phase 0 — Harness foundation

- 단일 범용 AI 지침
- 기획·아키텍처·ADR·계획 문서 구조
- 하네스 자동 검증

Exit criteria: 필수 문서와 링크 검증이 통과한다.

## Phase 1 — Product discovery

- 문제, 사용자, 가치 제안과 MVP 범위
- 핵심 사용자 여정과 검증 가능한 요구사항
- 성공 지표 및 주요 제약

Exit criteria: P0 요구사항이 Definition of Ready를 만족한다.

## Phase 2 — Architecture and contracts

- 서비스 책임, 데이터 소유권과 통신 방식
- 보안·개인정보·신뢰성 요구사항
- API/이벤트 계약 및 통합 검증 전략

Exit criteria: 서비스 저장소 생성에 필요한 미결 결정이 없다.

## Phase 3 — Repository bootstrap

- 정식 명칭 및 저장소 구조 확정
- 오케스트레이션 및 서비스 Git 저장소 생성
- submodule 연결
- 기술 스택별 실행 가능한 scaffold

Exit criteria: 신규 환경에서 모든 서비스와 통합 검증을 재현할 수 있다.

## Phase 4 — MVP delivery

- 우선순위 요구사항 구현
- 기능·계약·통합·운영 검증
- 사용자 피드백에 따른 컨텍스트 및 ADR 갱신

Exit criteria: 합의한 성공 지표로 MVP 결과를 평가할 수 있다.
