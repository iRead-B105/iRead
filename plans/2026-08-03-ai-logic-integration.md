# 아동 학습 AI 로직 선별 통합

- 상태: completed
- 작성일: 2026-08-03
- 수정일: 2026-08-03

## 목표

최신 완료 검사로 약점을 계산해 맞춤 훈련에 반영한다. 이야기 나라는 질문과 선택지 3개를 버튼·음성으로 제공한다. 현재 브랜치는 GMS 기반 맞춤 훈련 텍스트 생성과 고유 Backend·App 변경만 유지한다.

이야기·이미지 생성은 `feature/83-personalized-story-api`, 음성 변환·STT·발음·TTS는 관련 음성 브랜치를 기준 구현으로 사용한다. 현재 브랜치의 동일·유사 구현은 제외하고 이후 병합 시 계약만 맞춘다.

## 범위

### 포함

- 기존 Backend–AI `/api/v1` 계약, 인증과 요청 fingerprint 멱등성
- GMS 텍스트 기반 맞춤 훈련 후보 생성
- 타깃·제외 특성·난이도를 반영한 훈련 생성과 안전한 대체 문항
- 최신 완료 검사 선택, 일시 장애 1회 재시도와 외부 호출의 DB 잠금 구간 분리
- 이야기 질문·선택지·버튼·음성 제출과 실패 안내
- Mock/계약/통합 테스트와 공급자별 제한된 실호출

### 제외

- 추천 5개, 기준 템플릿 34개와 교수자 검수 재설계
- 과거 완료 데이터 소급 변경, 운영 DB·배포·장기 관측 인프라
- 실제 아동 데이터, 반복 유료 품질 평가, Eye Tracker 보정 변경

기준 데이터와 추천 검수는 [실력 도전 통합 검증 계획](2026-08-02-skill-challenge-integration-validation.md)을 따른다.

- 서비스별 PR과 직전 검증 gitlink로 독립적으로 되돌린다.
- 이야기 생성·음성 분석의 장시간 외부 호출은 일부 서비스 트랜잭션과 함께 실행된다. 현재 동시성 검증은 통과했지만 운영 부하 전 별도 트랜잭션 축소를 검토한다.

## 해결 사항

- Azure TTS는 SDK 파일 출력 경로에서 Windows 핸들을 먼저 해제하도록 수정한 뒤 `audio/mpeg` 18,288바이트, 4,475ms 실호출을 확인했다.
- Backend 운영 V3~V5와 데모 V3/V4 충돌은 데모 migration을 V6/V7로 이동해 해결했다.
- 계약 검증기는 V1/V2 기준선 뒤의 누적 migration을 허용하면서 전체 버전 중복을 차단하도록 갱신했다.
