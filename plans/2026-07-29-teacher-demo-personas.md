# 교수자 시연용 전체 아동 페르소나 데이터

- 상태: completed
- 작성일: 2026-07-29
- 대상: `services/backend`, Docker `iread_demo`, `services/frontend-web`

## 목표

교수자 소속 데모 아동 12명 각각에 고유한 읽기 학습 페르소나를 부여한다. 목록에서 보이는 기본 정보부터 학습 현황, 커리큘럼, 훈련 이력, 검사 이력, 시선 분석, 보고서와 이야기 진행 상태까지 한 아동 안에서 일관된 시연 서사를 제공한다.

## 품질 기준

- 아동별 고유한 강점·취약점·성장 방향과 교수자 메모
- 완료 커리큘럼 2개 이상과 현재 커리큘럼 1개
- 완료 훈련 8개 이상과 현재/대기 훈련
- 완료 검사 3개와 문항별 결과
- 성공 시선 결과 2개 이상, 일부 페르소나에는 과거 실패 이력
- 읽기 특징 프로필 4개 이상
- 기간별 보고서 2개 이상
- 완료 또는 진행 중인 이야기 2개 이상
- 화면에 `undefined`, `NaN`, 잘못된 배율 또는 불필요한 오류 상태가 없어야 함

## 작업

- [x] **DP-001** 12개 아동 페르소나와 수치 범위를 정의한다.
- [x] **DP-002** 재현 가능한 별도 데모 페르소나 시드를 구현한다.
- [x] **DP-003** 데모 초기화기가 기존 쇼케이스와 페르소나 시드를 독립적으로 적용하도록 한다.
- [x] **DP-004** Docker 데모 DB에 시드를 적용하고 아동별 최소 데이터 수를 검증한다.
- [x] **DP-005** 대표 아동과 경계 페르소나의 교수자 주요 화면을 검증한다.
- [x] **DP-006** 백엔드 전체 테스트와 MySQL 초기화 재현성 테스트를 실행한다. 프론트엔드는 변경하지 않았으며 기존 전체 테스트·빌드 결과를 유지한다.

## 검증

- 아동별 데이터 밀도 집계 SQL
- Flyway 및 데모 초기화기 재현성 테스트
- 교수자 웹의 학습 현황·커리큘럼·훈련·검사·보고서 화면 확인
- 백엔드 전체 테스트
- 프론트엔드 전체 테스트와 프로덕션 빌드
