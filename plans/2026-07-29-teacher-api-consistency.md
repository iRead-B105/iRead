# 교수자 앱 API 정합성 보정

- 상태: completed
- 작성일: 2026-07-29
- 대상: `contracts/openapi`, `services/backend`, `services/frontend-web`

## 목표

교수자 앱에서 발생한 `undefined%`, 다음 커리큘럼 404, 훈련 이력·통계 변환 오류, 시선 분석 변환 오류를 기준 계약에 맞게 해소하고 학생 메모 수정 계약의 회귀 검증을 추가한다.

## 확정 방향

- 학습 이력은 프론트엔드에서 `accuracyRate`를 `achievement`로 변환한다.
- 학생 메모는 범용 학생 수정 API를 유지하고 회귀 테스트로 요청 형식을 고정한다.
- 현재 커리큘럼 조회 API를 OpenAPI에 추가하고 전용 미존재 오류 코드를 사용한다.
- 훈련 이력은 프론트엔드 어댑터에서 백엔드 응답을 화면 모델로 변환한다.
- 훈련 통계는 현재 통계 API와 읽기 속도 API를 프론트엔드에서 조합한다.
- 시선 분석 원시 응답은 프론트엔드에서 화면 모델로 변환하고 404를 `NO_DATA`로 처리한다.

- [x] **TC-002** 백엔드가 현재 커리큘럼 미존재 시 전용 오류 코드를 반환하도록 구현하고 테스트한다.
