# 이야기 공급자 라우팅과 읽기 화면 개선

- 상태: active
- 수정일: 2026-08-04

## 범위

- 이야기 텍스트와 이미지를 각각 GMS, Gemini 직접 API, OpenAI 직접 API 중에서 선택하고 모델 이름을 독립적으로 설정한다.
- 공급자 전환은 서버 환경변수 변경과 AI 서비스 재시작으로 적용하며 API 키를 클라이언트에 노출하지 않는다.
- 신규 장면·캐릭터 이미지 생성 시 서버가 관리하는 원본 이야기 표지를 참조 이미지로 첨부한다.
- 이야기 선택 화면의 헤더, 카드 배치, 오류 잔상과 완료 탭 페이지네이션을 정리한다.
- 읽기 화면에 읽은 범위 안의 이전·다음 탐색과 텍스트·이미지 보기 모드를 제공한다.

## 작업

- [x] 제품·내부 API 계약과 공급자 라우팅 ADR을 반영한다.
- [x] GMS·Gemini·OpenAI 텍스트/이미지 공급자와 독립 모델 설정을 구현한다.
- [x] 템플릿 표지 참조 이미지 저장소와 생성 요청 연결을 구현한다.
- [x] 책장 헤더·카드·오류·완료 탭 페이지네이션을 개선한다.
- [x] 읽기 이전·다음과 텍스트/이미지 보기 모드 및 가독성 스타일을 구현한다.
- [x] 자동 테스트, 계약 검증과 브라우저 검증을 수행한다.

## 검증

- AI provider/config/image adapter 전체 테스트와 `ruff`
- Backend `./gradlew test`
- Frontend 관련 테스트, 타입 검사와 빌드
- `python tools/validate_contracts.py`, `python tools/validate_harness.py`
- 실제 GMS 이야기·Gemini 이미지 흐름과 표지 참조 로그 확인

## 미결 사항

- 실제 Gemini·OpenAI 직접 호출은 각 API 키가 설정된 환경에서 추가 확인한다. 키가 없을 때는 adapter 계약 테스트로 검증한다.
