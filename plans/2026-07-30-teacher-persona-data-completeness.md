# 교수자 UI 페르소나 데이터 완성도 보강

- 상태: completed
- 작성일: 2026-07-30
- 대상: `contracts/openapi/admin-api.yaml`, `services/backend`, `services/frontend-web`

## 목표

교수자 웹의 최신 화면이 요구하는 검사 해석, 훈련 비교, 정확도·읽기 속도 추이와 보고서 시선 추이를 모든 데모 아동에게 제공한다. 각 수치는 아동별 강점·취약점·성장 속도·읽기 속도 페르소나와 일관되어야 하며, 같은 관찰과 다음 지도 계획을 학생 상세의 교수자 메모에도 기록한다.

## 작업

- [x] **PC-001** 검사 비교 응답의 해석 필드를 OpenAPI와 Backend 응답에 명시한다.
- [x] **PC-002** 신규 아동을 포함한 모든 데모 아동의 페르소나와 교수자 메모를 완성한다.
- [x] **PC-003** 훈련 카탈로그, 이전 훈련 비교, 정확도·읽기 속도 추이를 보강한다.
- [x] **PC-004** 훈련 시선 추이와 검사 영역별 점수·권장 정보를 보강한다.
- [x] **PC-005** 깨끗한 MySQL 데모 DB와 교수자 웹 주요 화면을 검증한다.

## 품질 기준

- 모든 데모 아동에게 고유한 교수자 메모와 비식별 보호자 연락 정보가 있다.
- 모든 데모 아동의 검사 이력에 종합 점수, 변화량, 강점, 보완점, 영역 점수와 권장 과정이 표시된다.
- 모든 데모 아동에게 최근 30일 정확도·읽기 속도 추이가 3개 날짜 이상 존재한다.
- 전체 훈련 카탈로그에 페르소나별 기초 수행 기록이 있고, 최근 훈련은 이전 동일 훈련과 비교할 수 있다.
- 보고서의 훈련 시선 상태와 포인트가 서로 모순되지 않는다.

## 검증

- Backend 단위·계약 테스트
- MySQL 데모 시드 통합 테스트와 데이터 밀도 집계
- OpenAPI 및 문서 하네스 검증
- 교수자 웹 검사·커리큘럼·훈련·보고서 화면 확인

- 깨끗한 MySQL DB에서 13명 페르소나 시드 통합 테스트 성공

- 교수자 웹에서 교수자 메모, 34개 훈련 카탈로그, 훈련 정확도·시선 분석,
  검사 영역 점수·시선 분석과 보고서 시선 추이 표시 확인
