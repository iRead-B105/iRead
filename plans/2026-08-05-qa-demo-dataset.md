# QA 시연 데이터셋과 전용 Docker 환경

- 상태: local-verified (커밋 전)
- 수정일: 2026-08-06

## 범위

- `test@test.com` 교수자와 김도윤·이서연·박지호 세 아동만 반복 복원되는 QA 전용 데이터셋을 구성한다.
- 기존 demo seed가 섞이지 않도록 커리큘럼, 훈련, 검사, 이야기, 시선, 발음, 보고서를 명시적 reset 명령으로 교체한다.
- 월간 8회·최근 2주 4회의 학습 이력과 아동별 페르소나가 모든 상세 화면 및 보고서에서 일관되게 보이게 한다.
- 이야기 플롯 6종은 선택지로 유지하되 실제 이력은 김도윤 1권(9%), 이서연 1권(4%), 박지호 2권(완독 100%·진행 중 20%)만 둔다.
- 이야기 생성 계약은 하루 `본문 3페이지 → 독립 분기 질문 1페이지 → 본문 4페이지 → 독립 분기 질문 1페이지 → 본문 1페이지`, 총 10일·100페이지로 유지한다.
- 일반 이야기 페이지는 정확히 3문장, 분기 페이지는 독립 질문 1문장과 선택지 3개로 구성한다. QA 데이터의 본문 문장과 분기 질문은 한글 10~22음절이며, 읽은 모든 글자·단어에 대응하는 시선 원천 데이터를 둔다.
- 생성 구간 단위 장면 이미지 39장을 기존 표지와 일관된 그림체로 만들고 각각 1MB 이하로 저장한다.
- Azure 형식의 합성 발음 원천 JSON을 추가하고 음성형 검사 문항의 정규화 결과를 DB에 저장한다.
- 로컬 Docker 및 전용 reset까지만 완성하며 실제 외부 서버 배포는 제외한다.
- GitHub 커밋·push·PR·GitLab 동기화는 로컬 최종 검증 결과를 사용자에게 보고하고 별도 승인을 받은 뒤 수행한다.
